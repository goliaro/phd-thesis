\subsection*{Ethics statement}

This paper introduces a benchmark and evaluation methodology for GPU kernel generation.
It does not involve human subjects, crowdsourcing, or the release of a new high-risk generative model.
Tasks are derived from publicly available model architectures, libraries, and datasets.
The main dual-use consideration is that more efficient kernels can lower the cost of deploying large models; we mitigate silent failures by requiring production-faithful correctness checks before speedup credit is awarded.
The authors have read and adhere to the ICLR Code of Ethics.
